# House_price_prediction using XGBoost

This project demonstrates the use of the XGBoost regression model on the classic Boston Housing dataset to predict housing prices. The dataset is preprocessed, modeled, and evaluated using Python in a Google Colab notebook.

## 📌 Project Overview

- 📊 Dataset: [Boston Housing Dataset](https://lib.stat.cmu.edu/datasets/boston)
- 🧠 Model: XGBoost Regressor
- 🎯 Goal: Predict median value of owner-occupied homes
- 📈 Evaluation Metrics: R² Score, Mean Absolute Error (MAE)

## 🔧 Features

- Data loading and preprocessing from non-standard format
- Combining features spread across two lines
- Training XGBoost with performance tuning
- Model evaluation on both training and test sets
- Overfitting check
- Comments explaining each step
